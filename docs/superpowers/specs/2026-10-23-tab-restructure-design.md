# 하단 탭 재구성 설계 (오늘 / 레시피 / 기록 / 내 정보)

작성일: 2026-10-23 · 대상 브랜치: `feature/premium-features` (6.0.0에 함께 출시)

## 왜 하는가

지금 홈 화면에는 기능이 너무 많다. 위에서부터 주차·진행, 공지, 패스 배너, 식단 가이드(할 일·단식), 무탄수/저탄수 레시피 만들기, 체중 카드, 구독 기능 카드(편의점 판정·맞춤 추천·리포트), 저장한 레시피, 최근 만든 레시피가 한 화면에 쌓여 있다. 하단 탭은 홈·탐색 두 개뿐이고, 4주 리포트와 주간 리포트는 프로필 안에 숨어 있다.

사용자가 매일 하는 일은 **식단 가이드 체크, 단식 성공 체크, 체중 기록**이다(운영자 판단). 홈은 이 일만 남기고, 필요할 때 찾는 기능과 돌아보는 기능은 별도 탭으로 나눈다.

## 목표

- 하단 탭 4개: **오늘 / 레시피 / 기록 / 내 정보**.
- 오늘 탭은 "위에서부터 체크하면 오늘이 끝나는" 한 장짜리 화면.
- 지난 단식 결과를 언제든 고칠 수 있는 곳(기록 탭)을 만든다.
- 저장한 레시피, 4주 리포트처럼 지금 찾기 어려운 것을 탭에서 바로 찾게 한다.

## 하지 않는 것

- 새 시각 스타일을 만들지 않는다. 기존 디자인 언어(Pretendard, 초록 #16A34A, 주차별 색 `getWeekColor`/`getWeekColorHex`, 기존 버튼·카드·시트 컴포넌트)를 그대로 쓴다.
- 기능 자체(레시피 생성, 추천, 판정, 리포트 생성 로직)는 바꾸지 않는다. 화면 위치와 진입 경로만 바꾼다.
- 서버·DB 변경 없음. 단, 기록 탭의 지난 단식 결과 수정은 기존 `fasting_result` 테이블에 앱이 RLS로 쓰는 것이라 서버 변경이 필요 없다.

## 실패로 보는 것 (안티 목표)

- 매일 쓰는 동작(할 일 체크, 레시피 만들기 진입, 체중 기록, 단식 결과 응답)이 지금보다 한 번이라도 더 눌러야 하게 되는 것.
- 기존 링크가 깨지는 것: 푸시 알림의 `href`(`/report/{start}/{week}`, `/weight`), 공유 링크로 여는 레시피 상세, 카카오 링크.
- 패스 판매 중이 아닐 때 패스 관련 요소가 보이는 것(지금 규칙 유지).

## 결정된 구성

### 오늘 탭 (홈 대체)

**할 일 목록 하나로** 모은다(운영자 선택: 시안 A).

위에서부터:
1. 인사말, **N주차**(주차 색) + 톱니바퀴(시작일 재설정 시트 바로가기, 지금처럼 유지), 7일 진행 표시.
2. 공지 한 줄(지금의 최신 공지 줄 그대로, 누르면 전체 공지).
3. **단식 진행 중이면** 목록 위에 남은 시간 한 줄(진행 막대 포함). 지금 단식 카드의 "단식 중" 표시를 한 줄로 줄인 것.
4. **오늘 할 일** 목록(완료 수 표시, 예: 2/6):
   - 그날 식단 가이드 할 일들. "점심 저탄수식 먹기" "저녁 무탄수식 먹기" 같은 줄에는 지금처럼 **레시피 만들기** 버튼이 붙는다(누르면 기존 레시피 생성 화면).
   - **어제(지난) 단식 결과 질문**: 단식이 끝난 뒤 48시간 안이고 아직 답하지 않았으면 한 줄로 나온다. [성공] [중간에 먹음]. 답하면 결과가 표시되고 바꿀 수 있다(지금 `fastingResultWindow` 규칙 그대로: 단식이 끝난 뒤부터, 다음 단식 시작 전까지).
   - **오늘 체중 기록**: 오늘 기록이 없으면 [기록하기], 있으면 "69.4kg"와 [수정]. 누르면 지금의 체중 입력 시트.
   - 완료율(%)은 식단 할 일 기준으로 계산하는 지금 규칙을 유지한다. 단식 결과·체중 줄은 완료 표시만 하고 식단 완료율에는 넣지 않는다.
5. 목록 아래 작은 글씨: 이번 주 단식 요일(예: "단식 요일: 목 저녁 식후 · 바꾸기"). 단식이 있는 주차에서만. 누르면 지금의 단식 요일 설정 시트. 아직 정하지 않았으면 지금처럼 설정하라는 안내.
6. 유지기(5주차~)에는 할 일이 없으므로 지금의 유지기 안내를 목록 자리에 보여주고, 단식·체중 줄은 그대로 둔다.

오늘 탭에서 **빠지는 것**: 패스 배너, 무탄수/저탄수 레시피 만들기 큰 카드, 체중 카드(미니 그래프), 구독 기능 카드, 저장한 레시피, 최근 만든 레시피. 주차 진입 팝업(`WeekCompletePopup`)과 시작일 재설정 시트는 그대로 오늘 탭에 있다.

### 레시피 탭

위에서부터:
1. 검색창(지금 탐색의 검색 화면으로 이동).
2. **무탄수 / 저탄수 레시피 만들기** 두 카드(지금 홈의 카드).
3. **맞춤 추천**, **편의점 판정** 두 칸(지금 `PremiumFeatureCards`의 두 기능. 잠금·패스 표시 규칙 그대로).
4. **저장한 레시피** 가로 목록 + 모두보기(지금 화면).
5. **최근 만든 레시피** 가로 목록(지금처럼 모두보기 없음, 한 달 뒤 자동 삭제 안내 유지).
6. **다른 사람들의 레시피**: 한 줄짜리 진입 카드. 누르면 지금의 탐색 화면(인기 카테고리·목록·필터) 전체로 들어간다. 레시피 탭이 열릴 때 탐색 데이터를 미리 불러오지 않는다(가볍고 오프라인에서도 탭이 바로 열리게).

지금의 "탐색" 탭은 없어지고 그 화면은 레시피 탭 안에서 들어가는 화면이 된다. 탐색 탭에 붙어 있던 NEW 표시는 없앤다.

### 기록 탭

위쪽 3칸 전환: **체중 / 단식 / 리포트**.
- **체중**: 지금의 `/weight` 화면 내용(그래프, 시작일 대비 변화, 기록 목록, 수정·삭제, 전체 기간 보기, 오늘 기록하기).
- **단식**: 새 화면. 이번 프로그램의 단식일을 최근순으로 나열하고 각 날의 결과(성공 / 중간에 먹음 / 기록 안 함)를 보여준다. **어느 날이든 눌러서 결과를 고르거나 바꿀 수 있다**(48시간 제한 없음). 목록에 나오는 날 = (`fasting_plan`의 이미 시작된 계획일) ∪ (`fasting_result`가 있는 날), 둘 다 이번 프로그램(현재 시작일 이후) 안에서. 계획을 나중에 바꿔서 빠진 날이라도 결과가 있으면 보인다. 6.0.0 이전 주차처럼 계획 기록이 없는 날은 알 수 없으므로 목록에 없다(첫 주에 "이전 기록은 6.0.0부터 남아요" 같은 안내 한 줄). 이미 만들어진 주간 리포트의 숫자는 바뀌지 않는다(리포트는 만들 때의 기록으로 고정). 단식이 시작되지 않은 미래 날짜는 보이지 않는다.
- **리포트**: 맨 위에 **4주 리포트**(지금 프로필에 펼쳐져 있는 주차별 할 일 달성 내용을 그대로 옮김, 새 화면 없이 이 칸 안에 표시), 그 아래 **주간 리포트 목록**(지금 `/report` 목록, 이번/이전 프로그램 구분, 누르면 상세). 무료 사용자 미리보기 카드 규칙은 지금 그대로.

### 내 정보 탭

지금의 `app/profile.tsx`를 탭으로 옮긴다. 위에서부터:
1. 패스 카드(판매 중일 때만; 지금 프로필의 패스 영역).
2. 목록: 시작일(현재 날짜 + 바꾸기 → 시작일 재설정 시트), 체중 기록 알림(켜기/끄기, `user_setting.weight_reminder`, 켤 때 알림 권한 요청), 공지사항, 문의하기, 계정(로그인 방식, 로그아웃, 탈퇴 등 지금 프로필에 있는 것 전부). 단식 알림은 따로 켜고 끄는 설정이 지금 없으므로(단식 요일을 저장하면 기기 알림이 예약됨) 이번에 넣지 않는다.
3. 지금 프로필에 있는 "나의 4주 리포트", "주간 리포트" 진입은 기록 탭으로 옮기고 여기서는 뺀다.

오늘 탭 오른쪽 위 프로필 사진은 내 정보 탭으로 가는 바로가기로 남긴다.

## 바뀌지 않아야 하는 것 (제약)

- 푸시 알림 `href`와 딥링크가 그대로 열린다: `/report/...`, `/weight`, 레시피 상세, 카카오 링크, `/recommend?meal=...`, `/foodCheck`, `/pass`. 경로를 옮기면 이전 경로에서 새 경로로 넘겨준다.
- 오프라인에서도 오늘 탭이 지금처럼 열린다(6.0.0의 오프라인 화면 유지 동작).
- 태블릿·폴드 탭 바 수정(`tabBarLabelPosition: 'below-icon'`, 커스텀 버튼)과 Android 16 뒤로 가기·시트 닫기 동작 유지.
- 하단 시트·팝업은 공통 `CustomBottomSheet` 사용.
- 앱 버전·OTA 규칙: 6.0.0 스토어 빌드에 함께 들어간다(네이티브 변경 없음).

## 운영자가 정한 것

- 탭 4개: 오늘 / 레시피 / 기록 / 내 정보 (시안 C).
- 오늘 탭은 할 일 목록 하나로 (시안 A).
- 레시피·기록·내 정보 탭 구성은 위 제안 그대로 승인.
- 단식 결과는 단식이 끝난 뒤에 묻는다(이미 반영, 커밋 04be307).
- 지난 단식 결과를 고칠 수 있는 곳이 필요하다.

## 제가 정한 것 (운영자 확인 필요)

- 톱니바퀴(시작일 재설정)는 오늘 탭에 남기고 내 정보에도 둔다(두 곳).
- 완료율은 식단 할 일만 센다.
- 기록 탭의 단식 결과 수정에는 기간 제한을 두지 않는다.
- 탐색 탭의 NEW 표시는 없앤다.
- 오늘 탭 프로필 사진은 내 정보 탭 바로가기로 남긴다.
- 기록 > 단식 목록 = 시작된 계획일 ∪ 결과가 있는 날. 6.0.0 이전 기록은 없음.
- 4주 리포트는 새 화면 없이 기록 > 리포트 칸 맨 위에 그대로 옮긴다.
- 최근 만든 레시피에는 모두보기를 새로 만들지 않는다.
- 다른 사람들의 레시피는 한 줄 진입 카드(탐색 데이터 미리 안 불러옴).
- 내 정보에 단식 알림 설정은 넣지 않는다(지금 설정 기능이 없음).

## 빌더에게 맡기는 것

- 탭 아이콘 선택(기존 MaterialIcons 안에서), 화면 간 여백·글자 크기 세부.
- expo-router 폴더 구조(새 탭 그룹 이름, 기존 화면 파일 이동 방식)와 옛 경로 → 새 경로 넘겨주기 방법.
- 기록 탭의 3칸 전환 컴포넌트 구현 방식.
