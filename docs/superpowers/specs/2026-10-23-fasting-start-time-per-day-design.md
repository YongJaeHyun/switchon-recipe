# 단식 시작 시간: 요일마다 슬라이더로 설정

작성일: 2026-10-23 · 대상 브랜치: `feature/premium-features` (6.0.0)

## 왜
지금은 단식 시작 시간이 '아침 식후 / 점심 식후 / 저녁 식후' 중 하나이고, 고른 요일 모두에 같은 시간이 적용된다. 실제로는 어떤 날은 점심, 어떤 날은 저녁에 단식을 시작할 수 있다(운영자).

## 결정된 것 (운영자 승인)
- 단식 요일마다 시작 시각을 따로 정한다.
- 시각은 슬라이더로 고른다: 06:00 ~ 22:00, 30분 단위.
- 슬라이더 아래 빠른 선택 버튼: 아침 식후(09:00) / 점심 식후(13:00) / 저녁 식후(19:00).
- 요일을 새로 고르면 바로 전에 정한 시각(없으면 19:00)으로 미리 채운다.
- 시트에서 각 요일 줄: "목요일 · 19:00 시작 → 금 19:00 끝".
- 기존 사용자의 '저녁 식후' 등은 같은 시각으로 모든 요일에 옮긴다(체감 변화 없음).

## 데이터
- `fasting`, `fasting_plan`에 `start_minutes jsonb` 추가: `{ "<요일번호 0=일..6=토>": <자정부터 분, 0..1439> }`.
- 마이그레이션에서 기존 `start_time` 라벨을 분(아침 540, 점심 780, 저녁 1140)으로 바꿔 `days`의 모든 요일에 채운다.
- `start_time` 칸은 남긴다. 새 앱은 계속 쓰되 가장 가까운 라벨로 적는다(옛 앱·옛 서버 코드 호환). 읽을 때는 `start_minutes`가 우선, 없으면 `start_time` 라벨.

## 바뀌는 곳
- 시각을 쓰는 모든 계산: 단식 상태·남은 시간(`getFastingStatus`), 결과 응답 창(`fastingResultWindow`), 오늘 탭 줄(`todayExtraRows`), 기록 탭 단식 목록(`fastingHistory`), 단식 알림 예약, 서버 주간 리포트의 응답 대기 계산.
- 오늘 탭 요일 카드 문구: 요일마다 시각이 다를 수 있으므로 "토 19:00" 처럼 요일별로 보여준다.

## 하지 않는 것
- 24시간 고정은 그대로(끝나는 시각 = 시작 + 24시간).
- 단식 요일 규칙(주차별 횟수, 이틀 연속 금지, 다 고른 뒤 바로 바꾸기)은 그대로.

## 슬라이더
- 새 네이티브 라이브러리 없이 이미 있는 react-native-gesture-handler + reanimated로 만든다(6.0.0 네이티브 빌드 변경 없음).
- 접근성: 좌우로 30분씩 움직이는 accessibilityActions(increment/decrement) 지원.

## 추가: 일찍 끝낸 단식 기록 (운영자 승인)
- 단식 진행 중 진행 줄에 "일찍 끝냈어요" 버튼. 누르면 "지금까지 16시간 30분 단식했어요. 여기서 끝낼까요?" 확인 후 저장.
- 끝난 뒤 결과 질문의 두 번째 답 "중간에 먹음" → "일찍 끝냈어요". 고르면 몇 시간 했는지 슬라이더(1~23시간, 1시간 단위, 기본값 16)로 고른 뒤 저장.
- 저장: `fasting_result`에 `fasted_minutes integer null`(0~1440) 추가. `result`는 그대로 `'broken'`(옛 앱·서버 호환). 옛 앱이 남긴 `broken`은 시간 없이 "일찍 끝냈어요"로 보여준다.
- 일찍 끝낸 뒤 오늘 탭: 진행 줄 대신 "16시간 하고 끝냈어요 · 바꾸기" 결과 줄. 응답 창 안이면 결과 줄과 같은 모양.
- 표시 문구: 결과 줄 "16시간 하고 끝냈다고 기록했어요", 기록 탭 목록 "16시간 (일찍 끝냄)", 시간 없으면 "일찍 끝냄".
- 주간 리포트: 일찍 끝낸 단식의 시간도 근거로 쓴다("목요일 18시간 유지"). 시간 없는 기록은 지금처럼 중단 횟수만.
