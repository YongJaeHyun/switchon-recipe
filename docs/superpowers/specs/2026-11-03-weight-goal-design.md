# 체중 목표 설정 (6.1)

운영자 결정: 2026-10-30(내용), 2026-11-03(흐름·시안 승인). 시안: `.superpowers/brainstorm/79057-1793694908/content/weight-goal-flow.html`

## 왜
체중을 기록해도 "어디까지 가야 하는지"가 없어 기록이 쌓일 동기가 약하다. 목표를 한 번 정하면 기록 탭이 남은 거리와 진행률을 보여 주고, 닿으면 축하한다.

## 정한 것 (운영자)
- **목표 체중은 필수, 골격근량·체지방량 목표는 선택.** 골격근량 목표를 비우면 기본 목표는 "시작할 때보다 줄지 않기"(책 기준).
- **언제 묻나: 체중을 처음 기록할 때.** 첫 체중을 저장하면 같은 체중 기록 창이 닫히지 않고 목표 묻기 단계로 바뀐다 ("✓ 78.0kg 기록했어요" → "목표 체중을 정해 볼까요?"). [목표 저장] / [나중에 정할게요].
- **건너뛸 수 있다.** 건너뛰거나, 이미 체중 기록이 있는 6.0 사용자(처음 기록이 지난 사람)는 기록 탭 체중 칸에 "목표 체중을 정해 보세요 [정하기]" 카드가 보인다. 누르면 같은 목표 입력을 연다.
- **기록 탭 "목표까지" 카드** (체중 그래프 위): "목표 72.0kg까지 / 6.0kg 남았어요", 진행 막대, "시작 80.0kg → 지금 78.0kg · 25% 왔어요".
- **체중 그래프에 목표 점선** (라벨 "목표 72").
- **목표에 닿으면 1회 축하.**
- **서버 저장**: `user_setting`에 열 3개 (목표 체중, 골격근량 목표, 체지방량 목표). 폰을 바꿔도 남는다.

## 빌더에게 맡기는 것 (내 판단, 바꿔도 됨)
- 열 이름: `weight_goal_kg`, `muscle_goal_kg`, `fat_goal_kg` (numeric(4,1), null 허용). 새 열만 추가하므로 옛 앱에 영향 없음. 기존 RLS(본인 행) 그대로.
- "처음 기록"의 판정: 저장 직전에 이 사용자의 체중 기록이 0건이었고 목표가 없으면 목표 단계로. 목표 단계는 "목표 없음"인 동안 한 번만 자동으로 뜬다 (건너뛰면 같은 기기에서 다시 자동으로 묻지 않는다: 로컬 기억으로 충분).
- 시작 체중 = 지금 프로그램 시작일 이후 가장 이른 체중 기록 (기록 탭 "시작일부터 변화"와 같은 기준). 지금 = 가장 최근 기록.
- 진행률 = (시작 − 지금) / (시작 − 목표), 0~100%로 자른다. 목표가 시작 이상이면(증량 목표) 남은 kg만 보여 주고 진행률은 숨긴다.
- 닿음 = 지금 ≤ 목표 (감량 목표일 때). 카드는 "목표에 닿았어요" 상태로 바뀌고, 축하는 목표값별로 한 번 (같은 목표로 다시 축하하지 않음, 로컬 기억). 축하 모양은 앱의 기존 축하(주차 진입 팝업의 lottie 등)를 재사용.
- 목표 바꾸기: "목표까지" 카드를 누르면 같은 목표 입력을 기존 값과 함께 연다.
- 골격근량·체지방량 목표: 인바디 기록이 있을 때만 카드 아래에 작은 줄로 ("골격근량 27.1kg · 목표 이상 유지 중", "체지방량 19.8kg · 목표 17.0kg까지 2.8kg"). 인바디 기록이 없으면 안 보인다.
- 입력 검사: 20~250kg, 소수점 한 자리 (체중 입력과 같은 규칙 재사용).

## 하지 않는 것
- 목표 날짜, 주간 감량 속도 계산, 알림.
- 온보딩에서 묻기.
- 리포트(AI)에 목표 반영 — 나중.

## 지킬 것
- UI는 frontend-design 스킬, 기존 컴포넌트·디자인 언어(초록, 둥근 카드, Pretendard). 시트는 기존 WeightInputSheet 안에서 단계 전환 (새 바텀시트 만들지 않음).
- 문구는 쉬운 한국어, "회차" 금지.
- 순수 계산(진행률, 남은 kg, 닿음, 처음 기록 판정, 인바디 줄 문구)은 utils에 테스트 먼저.
- 마이그레이션은 만들되 반영하지 않는다 (운영자 승인 후 반영). 앱 코드는 열이 아직 없을 때(반영 전)도 깨지지 않게: 목표 조회 실패 → 목표 없음으로 보고 카드 숨김.
- 운영자 실계정 에뮬레이터: 체중·목표 저장 금지. 화면 확인은 저장 없이.

## 추가 (운영자 2026-11-03): 목표 달성 뒤 다음 목표, 지난 목표 표시
- **다음 목표**: 닿으면 축하 팝업에 [다음 목표 정하기] (목표 입력을 연다). 기록 탭 카드는 "목표 72.0kg에 닿았어요 🎉" + [새 목표 정하기]로 바뀐다 (팝업을 닫았어도 여기서 정할 수 있게).
- **새 목표의 진행률은 직전 목표에 닿은 지점부터** 다시 센다: 시작 = 직전 목표에 닿은 기록의 체중(첫 목표면 프로그램 시작 이후 첫 기록).
- **지난 목표도 그래프에**: 달성한 목표마다 그래프에서 닿은 날의 점에 작은 표시("✓ 72kg 달성")를 붙인다. 지금 목표만 점선. 지난 목표 선을 여러 개 긋지 않는다 (복잡해짐).
- **서버 저장**: `user_setting.weight_goal_history jsonb not null default '[]'` — 달성한 목표 목록 `[{ goal_kg, reached_on: 'YYYY-MM-DD', reached_kg }]`. 달성을 확인한 순간(앱이 지금 기록 ≤ 목표를 처음 본 때, 또는 저장 직후) 앱이 추가한다. 같은 목표값·같은 날 중복 추가 금지. 새 목표를 저장해도 기록은 남는다.
- 축하 1회 판정은 로컬 기억 대신 이 기록으로 한다 (기록에 없으면 축하 + 기록에 추가).
